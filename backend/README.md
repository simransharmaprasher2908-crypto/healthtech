# Healthcare Backend

This backend is built for a rural healthcare access and quality support platform.

## Setup

1. Install PostgreSQL.
2. Create the database and run the SQL schema.
3. Update environment variables in .env.
4. Run `npm install`.
5. Start the server with `npm start`.

## Default database

- DB name: `healthtech_db`
- User: `postgres`
- Password: `postgres`

## API base URL

- http://localhost:5000/api
